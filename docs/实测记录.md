## 主循环时序（已查清）

上报间隔实测 3.12 秒，设计值 2 秒（`mqtt_demo.cpp` 每 100 轮 `sleep_for(20ms)`）
每轮实测 31.25ms，其中循环体只占约 0.002ms
把 `sleep_for` 改成 `0ms` 实测 1000 轮只要 2ms，证明循环体本身几乎不花时间
多出来的 11.25ms 是 Windows 调度节拍（默认约 15.6ms）把 `sleep_for(20ms)` 向上取整到两个节拍所致，不是 `PollOnce()` 的锁竞争、也不是日志输出
